Computes min, max, median, and standard deviation from a ring buffer.

Iterates over all valid samples in {\ttfamily p\+\_\+handle} to find the minimum, maximum and arithmetic mean. A second pass computes the population standard deviation. The buffer is then copied to a temporary array, sorted with \doxylink{filter_8h_a5e9663576f3278f9024b85f531f8667a}{bubble\+\_\+sort()}, and the median is extracted.

\begin{DoxyNote}{Note}
The function returns immediately if the buffer is empty.
\end{DoxyNote}
