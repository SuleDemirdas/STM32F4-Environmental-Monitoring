\doxysubsection{Detailed Description}
AHT20 driver handle. 

Populate i2c\+\_\+read, i2c\+\_\+write and delay\+\_\+ms before calling \doxylink{aht20_8h_ab921181fa13a824dc250131c772f335f}{AHT20\+\_\+\+Init()}. After a successful \doxylink{aht20_8h_abf1692a1b6e3f2b0230bbd237d981dcf}{AHT20\+\_\+\+Read()} call the results are available in the humidity and temperature fields.
