\doxysubsection{Detailed Description}
Sliding-\/window median filter for floating-\/point sensor values. 

The filter maintains a fixed-\/size window of the most recent raw readings. Each call to \doxylink{filter_8h_aad9f632ebc697242cd6d89d9ad931391}{filter\+\_\+sensor\+\_\+value()} appends the new sample to the window (evicting the oldest one when full), sorts a copy of the window, and returns the median. This effectively suppresses impulse noise while preserving step changes faster than a moving-\/average filter of the same length.

Utility functions \doxylink{filter_8h_a5e9663576f3278f9024b85f531f8667a}{bubble\+\_\+sort()} and \doxylink{filter_8h_a92cc151d99a2b21ad40fe7e89da17248}{calculate\+\_\+median()} are also exposed so that \doxylink{main_8h_a95bd85dc1d64343eabe72f219491f9b9}{calculate\+\_\+statistics()} in \doxylink{main_8c}{main.\+c} can reuse them on the ring buffer.
