\doxysubsection{Detailed Description}
Circular (ring) buffer for float sensor samples. 

Provides a fixed-\/size, overwrite-\/on-\/full circular buffer used to store the most recent RING\+\_\+\+BUFFER\+\_\+\+SIZE filtered sensor readings. When the buffer is full, the oldest sample is silently overwritten by the newest one.
