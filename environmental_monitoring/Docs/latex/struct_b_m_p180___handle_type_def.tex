\doxysubsection{Detailed Description}
BMP180 driver handle. 

Populate i2c\+\_\+read, i2c\+\_\+write, delay\+\_\+ms and oss before calling \doxylink{bmp180_8h_a99ddc132d9283e29b1596a7446bc14cf}{BMP180\+\_\+\+Init()}. After a successful \doxylink{bmp180_8h_a3231bf959c4067be47d73f1dc942ed74}{BMP180\+\_\+\+Read()} the results are in temperature\+\_\+C and pressure\+\_\+\+Pa. The b5 field is an intermediate compensation value shared between the temperature and pressure calculation steps.
